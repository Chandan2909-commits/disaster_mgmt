# DisasterMgmt Chrome Extension

This Chrome Extension enables seamless, zero-config detection of local companion capabilities when visiting the DisasterMgmt prototype dashboard.

## How to install:
1. Open Google Chrome.
2. Navigate to `chrome://extensions/`.
3. In the top right corner, toggle **Developer mode** to ON.
4. Click **Load unpacked** in the top left.
5. Select this `extension` directory (`s:\prototype\extension` or unzipped folder).
6. Return to the dashboard. The dashboard will automatically detect the extension in the background without displaying any download prompt!
